# Button feedback

These original project sound effects were generated with ElevenLabs Sound
Effects v2 through fal.ai, then edited to mono PCM16 at 24 kHz. They contain no
recorded customer speech. The 38 ms Play click and 23 ms volume tick are included
under the project community license. Vendor request identifiers are omitted.

`tools/generate_button_sounds.py` embeds the supplied WAVs without a network
request. The test compares the compiled arrays against the source PCM.
